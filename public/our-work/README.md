# Our Work gallery assets (V2)

Optimized authentic job photos for `/our-work`.

## Rules
- Genuine Student Window Cleaning work only — no stock, AI, logos-as-work, or commercial storefronts in this pack
- House numbers and licence plates are privacy-masked or cropped before publish
- Do not invent captions, locations, or before/after claims
- Prefer WebP (JPEG fallbacks kept alongside)

## Source
Originals are preserved in the project media store (`media/our-work/source/`), not committed here.
Register every published file in `src/lib/our-work.ts`.

# Our Work media assets

Optimized authentic job photos retained for future project media integration.

The V3 `/our-work` page is a structural property portfolio with placeholders.
These files are **not** wired into the portfolio cards yet — do not delete.

## Rules
- Genuine Student Window Cleaning work only — no stock, AI, or logos-as-work
- House numbers and licence plates must be privacy-masked or cropped before publish
- Do not invent captions, locations, or before/after claims
- Prefer WebP (JPEG fallbacks kept alongside)

## Source
Originals are preserved in the project media store (`media/our-work/source/`), not committed here.
Catalogued in `src/lib/our-work.ts` as `workPhotos` for later reuse.
